Skills 2

business-presentation

/business-presentation

Turns any business idea description into a complete, investor-ready HTML presentation — executive summary, market sizing, business model, SWOT, roadmap, financial projections (with Chart.js charts), and more. Open in a browser and print to PDF.

  • Deep web research for real market data, competitors, and regulations
  • Detects input language and produces the document in kind
  • Self-contained .html output, no extra files needed
I want to open a modern pastry shop in Libreville, Gabon. Budget: 8 million FCFA.

tech-blog-writer

/tech-blog-writer

Turns a topic, a rough content draft, and optional reference links into a complete, publication-ready Markdown blog post — ready for Astro, Next.js, Hugo, Jekyll, or any Markdown-based CMS.

  • Fetches and reads any provided reference links
  • Asks targeted follow-up questions if the draft lacks substance
  • Covers tutorials, how-tos, comparisons, release notes, and migration guides
Turn my bullet points into a publishable article about React Server Components.

Install / Update

# Register the marketplace (once per machine)
claude plugin marketplace add ./

# Install into the current project
claude plugin install business-skills@smartb-skills-marketplace --scope project

# ...or make it available globally across all projects
claude plugin install business-skills@smartb-skills-marketplace --scope user

# Pick up changes after a new release
claude plugin marketplace update
claude plugin update business-skills@smartb-skills-marketplace
